# Liquor names are split by urban register — liquor_urban and liquor_suburban.
# The name is sign text, so the register has to match the building: a warehouse
# name on a narrow pre-war frontage reads as the wrong building. Urban is the
# independent shop on a walkable commercial corridor (numbered avenues,
# proprietor surnames, combined trades, initials, plain trade names); suburban
# is the wider unit with parking in front (discount, warehouse, beverage,
# plaza and highway references). Scene type picks the pool; see
# GenerationContext.PickLiquorName.
#
# A corner_shop run picks one origin kind (grocery or pharmacy) and keeps that
# name from the first era through 2005. From 2015 the shop is a liquor store
# under a new name, with the old one left as a ghost above it — the same
# building, a different business, which is the whole arc of this scene type.
#
# Names are rendered as sign text, so they must read as a real small-town
# storefront: no adjectives, no descriptions, nothing that could be mistaken
# for an instruction to the image model.
